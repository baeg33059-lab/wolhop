ABOUT WOLHOP

마인크래프트 Java 서버를 Wolhop에서 탐색하세요

Wolhop은 Minecraft Java Edition 커뮤니티 서버를 한곳에서 발견하고, 원하는 서버에 접속하도록 돕는 독립 플랫폼입니다.

원하는 서버 찾기

서버 이름, 주소, 소개를 검색하고 생존·미니게임·경제·건축·모드 등 서버 유형을 살펴보세요. 공개 서버의 소개와 대표 이미지를 확인할 수 있습니다.

Wolhop으로 플레이 시작하기

서버에서 플레이를 누르면 Wolhop 런처 설치 또는 실행으로 이어집니다. 런처에서 Microsoft 계정을 연결한 뒤 Minecraft Java Edition으로 접속을 진행할 수 있습니다.

지원하는 Minecraft 에디션

Wolhop은 PC용 Minecraft Java Edition 서버를 지원합니다. Bedrock Edition 서버는 지원 대상이 아닙니다.

독립 커뮤니티 플랫폼

Wolhop은 Mojang 또는 Microsoft와 제휴하거나 공식적으로 승인받은 서비스가 아닙니다. 서버 정보와 운영 정책은 각 서버 운영자 및 Wolhop의 검토 절차에 따릅니다.

Wolhop · Minecraft Java 서버 탐색독립 프로젝트이며 Mojang·Microsoft와 제휴되지 않았습니다.
