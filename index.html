Wolhop은 마인크래프트 Java Edition 커뮤니티 서버를 탐색하고, 선택한 서버에 접속하도록 돕는 독립 플랫폼입니다. 웹에서 공개 서버를 살펴보고 Windows 런처에서 플레이를 이어가세요.

Wolhop is an independent platform for discovering community servers for Minecraft: Java Edition and continuing play through its Windows launcher.

About Wolhop

서버를 찾는 경험부터
간단하게 만들어요.

서버 주소를 따로 찾아 복사하는 부담을 줄이고, 서버 소개와 접속 흐름을 한곳에서 이어 주는 런처와 디렉터리를 목표로 합니다.

01 / DISCOVER

커뮤니티 서버 발견

게임 방식, 버전, 서버 설명과 같은 정보를 살펴보고 관심 있는 서버를 찾도록 돕습니다.

02 / CHOOSE

원하는 서버 선택

접속 전에 서버 정보를 확인하고, 사용자가 선택한 서버로 이동하는 흐름을 설계하고 있습니다.

03 / PLAY

런처에서 게임 시작

승인과 구현이 완료되면 사용자의 정식 게임 계정과 공식 Minecraft 클라이언트를 이용하는 접속 경험을 목표로 합니다.

Development status

현재 개발 단계

Wolhop은 공개 서버 디렉터리와 Windows 런처를 제공하는 초기 서비스입니다. 서버별 접속 가능 여부와 호환 버전은 서버 운영 상태에 따라 달라질 수 있습니다.

초기 서비스

현재 제공하는 기능

  • 공개 Minecraft Java 서버 탐색과 검색
  • 서버 소개 확인과 개인 서버 저장
  • Windows용 Wolhop 런처 다운로드와 실행 연결
지원 범위

서비스 이용 안내

  • PC용 Minecraft Java Edition 서버를 지원합니다.
  • Bedrock Edition과 모바일 기기는 지원하지 않습니다.
  • 서버 버전 및 운영 상태에 따라 접속이 제한될 수 있습니다.
