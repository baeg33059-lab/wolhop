Wolhop은 Minecraft: Java Edition 커뮤니티 서버를 쉽게 발견하고, 선택한 서버에 간편하게 접속하는 경험을 만들고 있는 독립 프로젝트입니다.

Wolhop is an independent project in development, focused on helping players discover community servers for Minecraft: Java Edition and start playing with fewer steps.

About Wolhop

서버를 찾는 경험부터
간단하게 만들어요.

서버 주소를 따로 찾아 복사하는 부담을 줄이고, 서버 소개와 접속 흐름을 한곳에서 이어 주는 런처와 디렉터리를 목표로 합니다.

01 / DISCOVER

커뮤니티 서버 발견

게임 방식, 버전, 서버 설명과 같은 정보를 살펴보고 관심 있는 서버를 찾도록 돕습니다.

02 / CHOOSE

원하는 서버 선택

접속 전에 서버 정보를 확인하고, 사용자가 선택한 서버로 이동하는 흐름을 설계하고 있습니다.

03 / PLAY

런처에서 게임 시작

승인과 구현이 완료되면 사용자의 정식 게임 계정과 공식 Minecraft 클라이언트를 이용하는 접속 경험을 목표로 합니다.

Development status

현재 개발 단계

기능 상태를 투명하게 안내합니다. 이 페이지나 런처 프로토타입은 실제 게임 계정에 로그인하거나 서버에 접속하지 않습니다.

프로토타입

현재 준비된 것

  • Wolhop 런처 UI와 서버 탐색 화면 시안
  • 웹 디렉터리에서 런처로 연결하는 접속 흐름 설계
  • 제품 방향과 보안 요구사항 정리
개발 예정 · 미구현

아직 제공되지 않는 것

  • Microsoft / Xbox / Minecraft 계정 로그인 및 소유권 확인
  • 게임 파일 설치, Java 런타임 관리, 실제 게임 실행
  • 실제 운영 서버 목록과 원클릭 서버 접속
  • Minecraft 서비스 AppID 승인 요청 제출
